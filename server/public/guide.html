📷 폴더 카메라 사용설명서

현장 사진을 폴더별로 찍으면, 현장 클라우드로 자동으로 모여요.

어떤 폰을 쓰세요?

한눈에 보기

1

관리자에게 받은 초대 링크를 눌러요. (카톡으로 받음)

2

안드로이드는 앱 설치, 아이폰은 웹앱으로 현장에 들어가요.

3

현장 → 폴더(예: 01 전경사진)를 고르고 찍어요.

4

찍은 사진은 자동으로 현장 클라우드에 올라가요. 따로 보낼 필요 없어요.

꼭 지켜 주세요

  • 찍기 전에 맞는 폴더인지 확인하세요. 잘못 찍은 사진은 폴더를 옮길 수 없어요.
  • 처음 한 번 내 이름을 넣어 주세요. 사진 파일 이름에 붙어서 누가 찍었는지 알 수 있어요.
  • 초대 링크는 현장 사람에게만 보내 주세요.

🤖 안드로이드 사용법

1. 앱 설치 (처음 한 번)

1

카톡으로 받은 초대 링크를 눌러요. 자동으로 Chrome에서 열려요.

2

앱 내려받기 (APK)를 눌러요.

  • "유해할 수 있는 파일" 안내 → 다운로드
3

알림창이나 내 파일 → 다운로드에서 FolderCamera.apk를 눌러 설치해요.

  • "출처를 알 수 없는 앱" 안내 → 설정 → 이 출처 허용 켜기 → 뒤로 → 설치
⬇ 앱 바로 받기

옆 사람이 이미 앱을 쓰고 있다면, 그 사람 앱의 📤 앱 공유 → Quick Share로 바로 받을 수도 있어요.

2. 현장 참여

1

초대 링크를 다시 눌러 앱에서 바로 참여하기를 눌러요.

2

내 이름을 넣고 참여를 눌러요.

버튼이 안 되면: 앱 첫 화면 ☁ 현장 참여 → 초대 메시지를 통째로 붙여넣거나 초대 코드 6자리 입력

3. 촬영

1

첫 화면에서 🏗 현장을 누르고, 폴더를 눌러요.

2

흰 동그라미(셔터)나 음량 버튼을 누르면 찍혀요. 짧게 진동이 와요.

  • 줌: 두 손가락으로 벌리기 또는 아래 0.5× 1× 2×
  • 초점: 화면을 톡 누르기
  • 플래시: 오른쪽 위 ⚡ 끔/자동/켬
  • 삼성 카메라로 찍기: 위쪽 📷 삼성 (초광각·야간 등 삼성 기능 사용)
3

위쪽에 "☁ 업로드 대기 n장" → "☁ OneDrive 업로드 완료"로 바뀌면 다 올라간 거예요.

인터넷이 끊겨도 괜찮아요. 폰에 저장해 두었다가 연결되면 자동으로 올라가요. (앱을 꺼도 됨)

4. 찍은 사진 확인 (앨범)

셔터 왼쪽 작은 사진을 누르면 그 폴더 앨범이 열려요. (현장 화면에서는 폴더 ⋮ → 🖼 앨범 보기)

  • ☁ 모두가 올린 사진 현장 사람들이 올린 사진 전부 · 누르면 크게 보기, 📥 폰에 저장
  • 📱 이 폰에서 찍은 사진 내가 찍은 사진 (아직 안 올라간 것 포함)
  • 옆으로 밀어 넘기기 · 🔍 확대 보기로 초점 확인
  • 📤 보내기 카톡 등으로 보내기 · 🗑 삭제 폰에서만 지움

5. 폴더 관리

  • 현장 폴더 추가: 현장 화면 아래 + 새 폴더 만들기 (모든 사람에게 보여요)
  • 하위 폴더: 폴더 ⋮ → 📂 열기 · 하위 폴더 만들기 → 아래 + 새 폴더 (예: 03 공종별 사진 › 철근)
  • 📂 표시가 있는 폴더는 누르면 안으로 들어가요. 그 폴더 자체에 찍으려면 위쪽 📷 이 폴더에서 바로 찍기
  • 폴더 삭제: 폴더 오른쪽 ⋮ → 🗑 폴더 삭제 (현장 폴더는 비어 있을 때만 지워져요)
  • 내 폴더: 첫 화면 + 새 폴더 → 이 폰에만 저장, 업로드 안 됨
  • 폰에 있던 사진 올리기: ① 갤러리에서 사진 고르고 공유 → 폴더 카메라 → 현장·폴더 선택 ② 현장 폴더 ⋮ → 🖼 갤러리 사진 올리기 ③ 내 폴더 ⋮ → ☁ 현장 클라우드로 올리기
  • 현장 초대: 현장 화면 오른쪽 위 👥 초대

🍎 아이폰 사용법

아이폰은 앱을 설치하지 않아요. 사파리에서 여는 웹앱으로 써요.

1. 현장 참여

1

카톡으로 받은 초대 링크를 눌러요. 사파리로 넘어가요.

2

현장 참여하고 시작하기를 누르고 내 이름을 넣어요.

2. 홈 화면에 추가 (꼭 해 주세요)

1

사파리 아래쪽 공유 버튼 ⬆︎을 눌러요. (안 보이면 ⋯ → 공유)

2

홈 화면에 추가 → 추가

3

다음부터는 홈 화면의 📷 폴더카메라 아이콘으로 열어요.

3. 촬영

1

현장 → 폴더를 누르고 아래 📷 촬영을 눌러요.

2

아이폰 기본 카메라가 열려요. 찍은 뒤 사진 사용을 누르면 올라가요.

3

"☁ OneDrive에 1장 올라갔어요"가 뜨면 완료예요.

  • 이미 찍어 둔 사진은 🖼 고르기로 여러 장 한꺼번에 올려요.
  • 📂 표시 폴더는 하위 폴더가 있어요. 누르면 안으로 들어가고, 하위 폴더는 폴더 ⋮ → 📂 열기 에서 만들어요.
  • 폴더 화면에 모든 사람이 올린 사진이 보여요. 누르면 크게 보고, 길게 눌러 '사진 앱에 저장'.

알아 두세요

  • 웹앱으로 찍은 사진은 아이폰 '사진' 앱에 자동 저장되지 않아요. (클라우드에는 올라감)
  • 찍을 때 진동은 없어요. (아이폰 사파리 제한)
  • 올라가기 전에 웹앱을 닫았다면, 다시 열면 이어서 올라가요.
  • 📁 내 폴더는 이 아이폰 안에만 저장돼요. 중요한 사진은 📥 사진 앱에 저장을 눌러 두세요. 현장으로 보내려면 내 폴더 화면의 ☁ 현장으로 올리기.

🏗 현장 만들기 (현장 담당자)

내 OneDrive나 구글 드라이브의 폴더로 현장 사진을 모으고 싶을 때

1

현장 만들기 페이지를 열어요.

  • 안드로이드 앱: 오른쪽 위 ⋮ → 🏗 내 클라우드로 새 현장 만들기
  • 아이폰 웹앱: 첫 화면 🏗 내 클라우드로 새 현장 만들기 ›
2

OneDrive로 로그인 또는 Google Drive로 로그인

  • OneDrive는 개인 Microsoft 계정만 돼요. (회사 계정 X)
  • 구글에서 "확인되지 않은 앱"이 나오면 고급 → 이동
3

+ 새 현장 만들기 → 현장 이름 → 사진을 모을 폴더 고르기 → 현장 만들기

4

📤 초대 링크 보내기로 현장 단톡방에 보내면 끝!

🏗 현장 만들기 페이지 열기

관리

  • 같은 페이지에서 내 현장 목록, 초대 코드, 초대 다시 보내기, 삭제를 할 수 있어요.
  • 현장을 삭제하면 초대 코드만 막히고, 클라우드의 사진은 그대로 남아요.
  • 사진이 든 폴더 정리·삭제는 내 OneDrive/구글 드라이브에서 직접 해요.
  • 다른 폰에서 관리하려면 그 폰에서 같은 계정으로 다시 로그인하면 돼요.

🛠 문제 해결

다운로드가 계속 돌기만 해요
카톡 안에서 열린 경우예요. 링크를 Chrome(또는 삼성 인터넷)에서 열어 주세요. 새 링크는 자동으로 Chrome으로 넘어가요.
"출처를 알 수 없는 앱" 때문에 설치가 안 돼요
안내 창의 설정 → 이 출처 허용을 켜고 뒤로 돌아와 설치를 누르세요. 설치 후 다시 꺼도 돼요.
"업로드 대기"가 줄지 않아요
인터넷 연결을 확인하세요. 연결되면 자동으로 올라가요. 계속 안 되면 앱(웹앱)을 껐다 켜 보세요. "⚠ 업로드 실패"가 보이면 현장이 삭제됐거나 폴더 이름 문제일 수 있으니 현장 담당자에게 알려 주세요.
찍은 사진은 어디에 있나요?
폰: 갤러리에서 폴더 이름(예: 01 전경사진) 앨범 (안드로이드) · 아이폰은 웹앱 안
클라우드: 현장 담당자의 OneDrive/구글 드라이브 → 현장 폴더 → 폴더 이름
폴더를 잘못 만들었어요 / 삭제가 안 돼요
폴더 오른쪽 ⋮ → 폴더 삭제. 현장 폴더는 다른 사람 사진 보호를 위해 비어 있을 때만 지워져요. 사진이 있으면 현장 담당자가 클라우드에서 정리해요.
잘못된 폴더에 찍었어요
앱에서는 옮길 수 없어요. 맞는 폴더에서 다시 찍고, 잘못 올라간 사진은 현장 담당자에게 정리를 부탁하세요.
내 이름을 바꾸고 싶어요
안드로이드: ☁ 현장 참여에서 같은 초대 코드로 다시 참여하며 이름 입력
아이폰: 웹앱 첫 화면 오른쪽 위 👤 이름
앱 업데이트는 어떻게 하나요?
설치 페이지에서 다시 받아 설치하면 덮어써져요. 찍은 사진과 폴더는 그대로예요. 아이폰 웹앱은 자동으로 최신이에요.
그래도 안 되면
현장 담당자에게 화면 캡처를 보내 주세요.
