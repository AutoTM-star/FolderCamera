폴더 카메라 개인정보처리방침 및 이용약관

시행일: 2026년 10월 27일

1. 서비스 소개

폴더 카메라는 현장에서 찍은 사진을 폴더별로 정리하고, 현장 주인이 선택한 클라우드(OneDrive 또는 Google Drive) 폴더로 모아 주는 서비스입니다.

2. 수집하는 정보

  • 현장 주인: 클라우드 로그인 시 계정 이메일과 이름, 그리고 클라우드에 사진을 저장하기 위한 접근 토큰. 비밀번호는 받거나 저장하지 않습니다.
  • 참여자: 사진 파일 이름에 붙는 촬영자 이름(직접 입력한 경우). 별도 회원가입이나 로그인은 없습니다.
  • 사진: 참여자가 찍은 사진은 서버에 보관되지 않고, 현장 주인의 클라우드 폴더로 바로 전송됩니다. 일부 경우 전송을 돕기 위해 서버를 잠시 거쳐 가지만 저장하지 않습니다.

3. Google 사용자 데이터 사용

Google Drive 연결 시 drive.file 권한만 사용합니다. 이 권한으로는 이 서비스가 만든 폴더·파일과 사용자가 직접 고른 폴더에만 접근할 수 있으며, 그 밖의 드라이브 파일은 볼 수 없습니다. Google에서 받은 정보는 사진 업로드·목록 보기 기능에만 쓰이며, 광고나 다른 목적에 쓰거나 제3자에게 판매·제공하지 않습니다. 폴더 카메라의 Google API 사용은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

4. 보관 및 삭제

  • 로그인 토큰은 현장 주인이 서비스를 쓰는 동안 보관합니다.
  • 현장 주인은 언제든 Microsoft 계정(account.live.com/consent/Manage) 또는 Google 계정(myaccount.google.com/permissions)에서 이 앱의 접근 권한을 해제할 수 있으며, 해제하면 토큰은 더 이상 쓸 수 없습니다.
  • 클라우드에 올라간 사진은 현장 주인의 클라우드에 있으며, 현장 주인이 직접 관리·삭제합니다.

5. 이용 조건

  • 초대 코드를 받은 사람만 해당 현장에 사진을 올릴 수 있습니다. 초대 코드는 믿을 수 있는 사람에게만 공유하세요.
  • 타인의 권리를 침해하거나 법에 어긋나는 사진을 올려서는 안 됩니다.
  • 서비스는 있는 그대로 제공되며, 사진 보관의 최종 책임은 클라우드를 소유한 현장 주인에게 있습니다.
